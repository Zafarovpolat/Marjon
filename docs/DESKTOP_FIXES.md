> **Кодировка сида (17.08):** при запуске через `start.cmd` `seed.py` падал с `UnicodeEncodeError: 'charmap' codec can't encode character 'ғ'` на строке 424 (`print` названия «Фарғона филиал», символ ғ). Причина — Python берёт кодировку stdout из локали Windows (`cp1251`), где узбекской кириллицы (ғ/қ/ў) нет; краш происходил **до** `commit`, поэтому `dev.db` не портилась, но лаунчер рапортовал ошибку. **Фикс:** `seed.py` в самом верху переводит `sys.stdout`/`sys.stderr` на UTF-8 (чинит любой запуск, включая ручной `python seed.py`), а `start.ps1` выставляет `PYTHONUTF8=1`/`PYTHONIOENCODING=utf-8` для всех python-процессов (сид, миграции, бэкенд-логи с echo). Причина — лаунчер: `start.ps1` переопределяет `ALLOWED_ORIGINS` (переменная приоритетнее `.env`) и сужал список до одного `:5173` (`http://localhost:5173,http://127.0.0.1:5173,http://<LAN-IP>:5173`), хотя дефолт в `config.py` порт 5174 содержит. Preflight с `Origin: http://localhost:5174` не проходил, Starlette `CORSMiddleware` отдавал 400 «Disallowed CORS origin» (методы/заголовки — `*`, значит виноват только origin). **Фикс:** в `start.ps1` объявлен `$DesktopPort = 5174`, в `$origins` добавлены `http://localhost:5174,http://127.0.0.1:5174` (десктоп на этой же машине — LAN-IP ему не нужен). Проверено рантаймом (мидлварь как в `main.py:117-122`, парсинг как в `config.py`): preflight с `localhost:5174` и `127.0.0.1:5174` → **200**, веб-фронт `:5173` → **200** (без регресса), чужой origin → **400**.
